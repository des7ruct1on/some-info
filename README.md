## `mlops-start-sample` - мини-проект по mlops
Настраивал `airflow`, `mlflow`, `hadoop`, `jupyter` самостоятельно и поднимал все контейнеры в Docker`е

Некоторые данные/тетрадки внутри папки `aflow/dags`:
- `taxi.ipynb` - делал для себя что-то с временными редами и трекал в mlflow (SARIMA, Auto_arima, Prophet, NeurolProphet) (есть некоторые комментарии в ячейках)
- `Trees.ipynb` - загружал данные из hadoop для обучения некоторых деревянных моделей, все делал чисто для себя, потому комментариев не оставлял, только пушил артефакты и логи в mlflow
- `train_dag.py` - простенький даг для обучения модели (просто для себя)
- `dag_inference.py` - даг для скора модели (просто для себя)

[Ссылка на репу](https://github.com/des7ruct1on/mlops-start-sample)

## `Сайт по продаже автомобилей` - проект в рамках вуза
### Технический стек:
- `backend`: FastAPI + Python
- `frontend` : React + TypeScript
- `СУБД`: PostgreSQL

Реализована клиентская и админ-панель, во второй можно изменять цены, добавлять/изменять/удалять ячейки из таблиц, делать бэкап/загружать бэкап.   

Весь проект стартует в докере, операции с БД реализованы через хранимые процедуры, есть триггеры, представления.

Авторизация идет через JWT-токены как положено, для удобства по всему проекту протянут логгер и обработка всех исключений как следует

[Ссылка на репу](https://github.com/des7ruct1on/cw_bd/tree/main)
